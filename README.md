# 城签 · City Sign

日签式城市卡片生成器网页。输入城市名即可生成一张可收藏的城市卡片，包含城市头图、世界位置图、经纬度、基本信息（洲/国家/地区/气候/人口/面积/半球）、时区与当地时间、当日日出日落、签名句与名句，以及可选的当地日期与天气。

## 功能

- 城市搜索与随机抽取，支持按洲/地区筛选
- 五种款式：经典日签 / 杂志封面 / 极简 / 星夜 / 签证章
- 经纬度中文式与符号式切换
- 可选当地当日日期与天气
- 多城市对比与单城位置图

## 使用

直接用浏览器打开 `index.html` 即可，无需构建、无需联网依赖。

数据为约数，天气来自 Open-Meteo 公共 API，时区与日出日落为本地计算值，仅供参考。
